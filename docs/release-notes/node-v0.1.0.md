`@libmorpheus/node` 0.1.0 — first release of the Node.js binding: asynchronous Greek and Latin analysis and experimental Greek generation through a stable Node-API addon; acquires native libmorpheus 0.3.2 (C ABI 2).

Install: `npm install @libmorpheus/node@0.1.0`, then `npx libmorpheus-setup --dataset perseids`

Assets: the four npm tarballs (`@libmorpheus/node` and its three platform addon packages) and `SHA256SUMS`.

Release decision: [release-node-0.1.0.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-node-0.1.0.md)
