Native libmorpheus 0.5.0 — C ABI 2, SONAME 1. Experimental generation no longer fails a lemma on one bad record; analysis is unchanged.

- Generation: a record the engine cannot generate is skipped and counted instead of failing the whole lemma (δίδωμι, ἵστημι, πόλις, γράφω and βασιλεύς failed before). New function `morpheus_generation_result_skipped_records()`, an ABI 2 addition: existing callers are unaffected.
- Generation: records carry the degree and morphology flags analysis reports (ἡδύτερος is comparative, no longer positive), and surfaces lose the stem-boundary hyphen (`a)nqrw/pwn`).
- Contexts opened through the public API no longer print the engine's diagnostics; `cruncher` still does.
- Fixed: a leak when a generation record failed after its keys were scanned.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
