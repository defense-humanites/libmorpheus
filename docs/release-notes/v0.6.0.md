Native libmorpheus 0.6.0 — C ABI 2, SONAME 1. Experimental generation now returns compound verbs and the forms analysis reads beyond the stem data; analysis is unchanged except one reading.

- Generation: `morpheus_generate()` accepts the compound verbs analysis reports (`a)podi/dwmi`, `a)mfi/-lu/w`) and returns their preverb variants (κάββαλε, ἠφίει, ἀπίκετο); the new flag `MORPHEUS_GENERATION_EXCLUDE_PREVERB_VARIANTS` leaves them out. C ABI 2 unchanged.
- Generation: unaugmented indicatives (ἄγον), movable ν of irregular forms (ἀνδράσιν) and accented clitics (ὅ, ἐστί, τινός), as analysis reads them; each form has the dialects all its parts allow; verbal adjectives in -τός stay with their own lemma.
- On the AGDT 2.1 treebank, the readings analysis gives that generation returns rise from 82.8 % to 95.2 %. Generation takes about twice as long for a large verb.
- The default generation limit becomes 65,536 records instead of 4,096.
- Fixed: a leak and a double free in the stem expansion; Attic labels on first-declension endings in -η after ρ, ε, ι (χώρην is Ionic and epic, and so is χρῆς in analysis).

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
