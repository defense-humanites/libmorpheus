`libmorpheus` 0.1.0 for Python 3.11+ — first release of the Python binding: Greek and Latin analysis and experimental Greek generation through `ctypes`, with no compiled extension; targets native libmorpheus 0.3.2 (C ABI 2).

Install: `pip install libmorpheus==0.1.0`

Assets: the universal wheel, the source distribution and `SHA256SUMS`.

Release decision: [release-python-0.1.0.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-python-0.1.0.md)
