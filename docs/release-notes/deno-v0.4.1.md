`@libmorpheus/deno` 0.4.1 — acquires native libmorpheus 0.4.1 (C ABI 2). **Known regression: that runtime may abort the process on some Greek forms; use 0.4.2.**

Install: `deno add jsr:@libmorpheus/deno@0.4.1`

Assets: the standalone binding archive with its `.sha256` sidecar.

Release decision: [release-deno-0.4.1.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-deno-0.4.1.md)
