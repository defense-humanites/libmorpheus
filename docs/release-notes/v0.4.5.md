Native libmorpheus 0.4.5 — C ABI 2, SONAME 1. Resolves the stem classes the stem-type tables name and refuses unknown ones.

- Latin: analyses built on the fourth principal part (`amatus`, `captum`…) are restored on 32-bit targets, where they were dropped (#37); WebAssembly 0.1.3 is compiled from this release.
- Native results change in one respect: the perfect participles of deponent and semi-deponent lemmas are reported as deponent instead of passive (12 of 1,517 Latin headwords). Greek results are unchanged.
- A stem-type table naming an unknown class is now refused with a diagnostic on every platform.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
