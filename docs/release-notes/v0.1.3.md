Native libmorpheus 0.1.3 — C ABI 1, SONAME 0. Licensing and packaging release; runtime unchanged.

- The Deno binding is licensed AGPL-3.0-or-later, independently of the MPL-2.0 native library.
- Fixture tests no longer require Ruby.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, the standalone Deno binding archive, and the accepted benchmark report.
