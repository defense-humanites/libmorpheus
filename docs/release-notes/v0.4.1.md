Native libmorpheus 0.4.1 — C ABI 2, SONAME 1. **Known regression: may abort the process on some Greek forms; use 0.4.2.**

- Greek analysis grows its result storage on demand instead of failing at 25 analyses.
- Stemlib production no longer requires Perl; all 229 reviewed binary stem-table differences are decoded and compared record by record.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
