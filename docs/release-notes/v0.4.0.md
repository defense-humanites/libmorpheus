Native libmorpheus 0.4.0 — C ABI 2, SONAME 1. Reproducible stemlib production and independent binding releases.

- Opt-in `morpheus_stemlib_production` target rebuilds the Greek and Latin distributions from sources, with deterministic receipts.
- Bindings are now versioned and released on their own tracks (`deno-v*`, `node-v*`, `python-v*`); first Node.js and Python bindings.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
