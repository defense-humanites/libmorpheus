`@libmorpheus/wasm` 0.1.3 — compiled from libmorpheus 0.4.5 (C ABI 2) with Emscripten 4.0.15. Contains no linguistic data.

- Latin: restores every analysis built on the fourth principal part (`amatus`, `captum`…), which 0.1.0 to 0.1.2 return nothing for (#37). Results now equal the native library's; Greek is unchanged.

Install: `npm install @libmorpheus/wasm@0.1.3` · `deno add jsr:@libmorpheus/wasm@0.1.3`

Assets: `morpheus.mjs`, `morpheus.wasm` and `SHA256SUMS`.

Release decision: [release-wasm-0.1.3.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-wasm-0.1.3.md)
