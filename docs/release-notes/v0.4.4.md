Native libmorpheus 0.4.4 — C ABI 2, SONAME 1. No change to analysis or generation results.

- Index files are read in one request instead of thousands: the first analysis of a WebAssembly context falls from 10–15 ms to about 6 ms; native builds issue fewer system calls.
- WebAssembly 0.1.2 is compiled from this release.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
