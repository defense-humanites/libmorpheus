`@libmorpheus/wasm` 0.1.4 — compiled from libmorpheus 0.4.6 (C ABI 2) with Emscripten 4.0.15. Contains no linguistic data.

- Analysis about twice as fast as 0.1.3 with the stem data in memory, from the runtime changes of native 0.4.6. Results and facade are unchanged.

Install: `npm install @libmorpheus/wasm@0.1.4` · `npx jsr add @libmorpheus/wasm@0.1.4`

Assets: `morpheus.mjs`, `morpheus.wasm` and `SHA256SUMS`.

Release decision: [release-wasm-0.1.4.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-wasm-0.1.4.md)
