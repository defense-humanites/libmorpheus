`@libmorpheus/node` 0.1.2 — Node-API binding; acquires native libmorpheus 0.3.2 (C ABI 2).

- Data acquisition now comes from `@libmorpheus/data` 0.1.0: `libmorpheus-data` gains `--subset runtime`, `--languages` and `--manifest`.

Install: `npm install @libmorpheus/node@0.1.2`, then `npx libmorpheus-setup --dataset perseids`

Assets: the four npm tarballs (`@libmorpheus/node` and its three platform addon packages) and `SHA256SUMS`.
