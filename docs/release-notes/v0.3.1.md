Native libmorpheus 0.3.1 — C ABI 2, SONAME 1. Deno distribution release; the native runtime is unchanged.

- JSR `/setup` command installs the native archive and Alpheios or Perseids data in one step.
- The bundled generation preparer loads correctly from its remote JSR URL.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, the standalone Deno binding archive, and the accepted benchmark report.
