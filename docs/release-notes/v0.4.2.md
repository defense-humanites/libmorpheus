Native libmorpheus 0.4.2 — C ABI 2, SONAME 1. Fixes the 0.4.1 regression.

- Analysis storage no longer double-frees when it grows: forms such as `a)mfestan` no longer abort the process. The 46 reported forms and an Alpheios lemma sweep are regression tests.
- Replaces 0.4.1, which must not be deployed for untrusted searches.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
