Native libmorpheus 0.2.0 — C ABI 2, SONAME 1. C ABI 2: public morphology values independent of the historical encodings.

- Morphology traits are a complete 84-trait public bitset; opaque `stem_type` and `derivation_type` are removed from `morpheus_analysis`.
- Historical formatter declarations move to `<morpheus/compat.h>`.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, the standalone Deno binding archive, and the accepted benchmark report.
