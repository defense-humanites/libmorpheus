`@libmorpheus/node` 0.1.1 — Node-API binding; acquires native libmorpheus 0.3.2 (C ABI 2).

- The `libmorpheus-native`, `libmorpheus-data` and `libmorpheus-setup` commands now run when invoked through npm (`npx`, `node_modules/.bin`).

Install: `npm install @libmorpheus/node@0.1.1`, then `npx libmorpheus-setup --dataset perseids`

Assets: the four npm tarballs (`@libmorpheus/node` and its three platform addon packages) and `SHA256SUMS`.
