Native libmorpheus 0.3.2 — C ABI 2, SONAME 1. The Deno native installer materializes shared-library aliases as regular files, so scoped Deno permissions suffice.

- Native runtime unchanged from 0.3.1.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, the standalone Deno binding archive, and the accepted benchmark report.
