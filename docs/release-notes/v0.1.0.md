Native libmorpheus 0.1.0 — C ABI 1, SONAME 0. First release: a C17 shared library with a versioned opaque ABI over the Morpheus analyzer.

- Structured, caller-owned results with explicit statuses; a typed Deno FFI binding; `cruncher` as a client of the library.
- CMake and `pkg-config` packages.

Assets: a data-free archive for Linux x86-64 with its `.sha256` sidecar, and the benchmark report.
