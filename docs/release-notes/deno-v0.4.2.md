`@libmorpheus/deno` 0.4.2 — acquires native libmorpheus 0.4.2 (C ABI 2).

- Replaces 0.4.1, whose native runtime could abort the process on some Greek forms. Install the new runtime in a fresh directory: `/setup` and `/native` do not overwrite.

Install: `deno add jsr:@libmorpheus/deno@0.4.2`

Assets: the standalone binding archive with its `.sha256` sidecar.

Release decision: [release-deno-0.4.2.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-deno-0.4.2.md)
