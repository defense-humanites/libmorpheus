Native libmorpheus 0.4.3 — C ABI 2, SONAME 1. No change to analysis or generation results.

- Builds cleanly on ILP32 targets (32-bit `long`, as on wasm32); LP64 behavior is unchanged.
- Regularizes the provenance of the WebAssembly binding: 0.1.1 is compiled from this release.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
