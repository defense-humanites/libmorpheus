Native libmorpheus 0.4.6 — C ABI 2, SONAME 1. Analysis about three times faster, results unchanged.

- Analysis: five runtime hot spots found by profiling are removed (a preverb flag transfer that tested 112 flags per candidate key through thread-local reads, per-context comparison tables, repeated context reads, full raw-preverb comparisons, and a stem index opened about five times per word). `cruncher` analyzes 24,000 words in 4.9 s instead of 14.8 s on Apple Silicon; output is byte-identical.
- A context now keeps up to four stem index files open until it is destroyed.
- Fixed: a memory leak in the generation source preparer (not linked by the library); the sanitizer CI now runs with leak detection.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, and the accepted benchmark report.
