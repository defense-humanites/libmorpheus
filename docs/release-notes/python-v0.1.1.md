`libmorpheus` 0.1.1 for Python 3.11+ — `ctypes` binding; targets native libmorpheus 0.4.5 (C ABI 2).

- Declares native 0.4.5 instead of 0.3.2, with its Latin fixes; the binding's source is unchanged.

Install: `pip install libmorpheus==0.1.1`

Assets: the universal wheel, the source distribution and `SHA256SUMS`.

Release decision: [release-python-0.1.1.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-python-0.1.1.md)
