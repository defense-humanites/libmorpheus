`@libmorpheus/wasm` 0.1.0 — first release of the WebAssembly binding, for servers, browsers and Cloudflare Workers. Contains no linguistic data.

- **Does not work from JSR** (use npm, or 0.1.1); **Latin defect** fixed in 0.1.3.

Install: `npm install @libmorpheus/wasm@0.1.0` · `deno add jsr:@libmorpheus/wasm@0.1.0`

Assets: `morpheus.mjs`, `morpheus.wasm` and `SHA256SUMS`.

Release decision: [release-wasm-0.1.0.md](https://github.com/defense-humanites/libmorpheus/blob/main/docs/release-wasm-0.1.0.md)
