Native libmorpheus 0.3.0 — C ABI 2, SONAME 1. Experimental Greek generation.

- C API: owned lemma-generation results with typed filters and explicit result limits; Deno binding: `generate()` and `generateRaw()`.
- JSR `/data` and `/native` commands acquire pinned stem data and the matching native archive without Git or a C toolchain.

Assets: data-free archives for Linux x86-64 glibc, Linux aarch64 glibc and macOS arm64, each with a `.sha256` sidecar, the standalone Deno binding archive, and the accepted benchmark report.
